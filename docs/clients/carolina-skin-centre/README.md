# Carolina Skin Centre

Client website maintained by Cicero Web Studio.

- `context/`: client facts, sources and content boundaries.
- `releases/`: scoped website change notes.
- `verification/`: release checks and pending owner/provider verification.

Website content lives in `src/`. Services are defined in `src/components/blog/servicesPageCard.js`, treatment articles and FAQs in `src/data/serviceDetailContent.js`, contact destinations in `src/constants/index.js`, and studio policies in `src/components/PolicyComponent/policies.js`.
